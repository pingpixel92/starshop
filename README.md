# استار شاپ — STARSHOP

پلتفرم **خدمات پرداخت و سرویس‌های بین‌المللی** — وب‌سایت رسمی (استاتیک، فارسی/RTL).

پرداخت‌های بین‌المللی · حساب‌ها و PayPal · کارت‌های Visa/MasterCard · گیفت کارت · اکانت‌های هوش مصنوعی و Premium · خرید خارجی · درآمد ارزی · آزمون‌های بین‌المللی · کیف پول سخت‌افزاری

## 🌐 دامنه عمومی (GitHub Pages)

```
https://pingpixel92.github.io/starshop/
```

هر push به شاخه `main` به‌صورت **خودکار** دوباره منتشر می‌شود (GitHub Pages از شاخه `main / root` سرو می‌کند). نیازی به build نیست.

## 🗂 ساختار

```
starshop/
├── index.html              # تک‌صفحه کامل (تمام سکشن‌ها)
├── assets/
│   ├── css/style.css       # دیزاین‌سیستم (تم روشن/تاریک، RTL، ریسپانسیو)
│   ├── js/main.js          # تعاملات (لودر، مودال، جستجو، تب، کاروسل، فرم…)
│   ├── js/three-scene.js   # لایه WebGL (ذرات + شبکه جهانی) با فالبک
│   ├── favicon.svg
│   └── og.png
├── robots.txt · sitemap.xml · .nojekyll
```

## ▶️ اجرای محلی

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## ✏️ موارد قابل ویرایش (پس از تأیید مالک)

- **ایمیل پشتیبانی:** `support@starshop.example` (جایگزین شود)
- **تلفن پشتیبانی، شبکه‌های اجتماعی:** در سکشن تماس و فوتر
- **نظرات کاربران:** سکشن «تجربه کاربران» (placeholderهای علامت‌دار)
- **لینک مقالات مجله:** در حال حاضر «به‌زودی»

هیچ آمار جعلی، لایسنس یا شریک تجاری ساختگی در سایت وجود ندارد؛ آمار نمایش‌داده‌شده صرفاً ساختاری (تعداد دسته‌های خدمت و…) است.

## 🛠 فنی

- HTML + CSS + Vanilla JS — بدون فریمورک
- Vazirmatn (CDN) · Lenis (اختیاری، با فالبک) · Three.js (اختیاری، با فالبک CSS)
- دسترس‌پذیری: ARIA، فوکوس‌پذیری، `prefers-reduced-motion`
- SEO: متاتگ‌ها، Open Graph، JSON-LD، sitemap
