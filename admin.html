🤖 مدیریت کامل فروشگاه هوش مصنوعی: همه‌ی سرویس‌ها با پلن‌ها و قیمت پایه دلاری، نام‌ها، دسته‌بندی، «ناموجود»، افزودن و حذف. قیمت نهایی = (دلار + ۱$) × نرخ لحظه‌ای دلار + حق خدمات. لوگوی هر سرویس از assets/logos/ai/id.webp می‌آید (تب تصاویر).

ریجن‌ها (کشورها)

📝 دسترسی کامل به همه‌ی متن‌های سایت در سه زبان: جستجو کنید، مقدار را عوض کنید و «انتشار» بزنید — فقط فیلدهای تغییرکرده (حاشیه نارنجی) ذخیره می‌شوند. بخش «سایر بخش‌ها» هر داده‌ی ساختاری سایت را JSON ویرایش می‌کند (برای کاربر حرفه‌ای).
۰ تغییر ذخیره‌نشده
🖼 عکس‌ها مستقیم در مخزن گیت‌هاب ذخیره می‌شوند. jpg/png خودکار به webp فشرده تبدیل می‌شود (لوگو حداکثر ۵۱۲px، تصویر بازی ۶۴۰px). نام فایل = همان id محصول (مثلاً freefire.webp).
برای مدیریت تصاویر، توکن گیت‌هاب بدهید.
🧩 مثل افزونه‌های وردپرس — هر بخش را می‌توانید روشن/خاموش کنید. خاموش‌کردن = حذف کامل از سایت بدون دست‌زدن به داده‌ها (هر وقت خواستید دوباره روشن کنید).

🔑 توکن گیت‌هاب

برای ذخیره‌ی تغییرات (کامیت در مخزن)، یک توکن شخصی بسازید:
GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained ← Generate new ← Repository access: Only select repositories ← starshop + starshop2 (هر دو) ← Permissions ← Contents: Read and write ← Generate.
توکن فقط در همین مرورگر ذخیره می‌شود و هرگز جایی ارسال/کامیت نمی‌شود.
